📖 Sobre este Projeto

Neste projeto vamos transformar um smartphone Android antigo em um console portátil utilizando emuladores gratuitos. Com poucos aplicativos é possível jogar consoles clássicos como NES, SNES, Mega Drive, Game Boy, PlayStation 1 e PSP.

Todo o processo é apresentado passo a passo para que qualquer pessoa consiga montar seu próprio console retrô.

✔ Requisitos

  • Android 7.0 ou superior
  • 2GB de memória RAM
  • Bluetooth
  • USB OTG (Opcional)
  • Cartão SD (Opcional)

📲 Aplicativos Utilizados

🎮 DuckStation

Emulador de PlayStation 1 com excelente desempenho, suporte a melhorias gráficas e alta compatibilidade.

🕹 RetroArch

Plataforma completa para diversos consoles clássicos utilizando Cores oficiais.

🎲 PPSSPP

Melhor emulador de PSP para Android, extremamente leve e rápido.

🪜 Passo a Passo

1

Prepare o celular

Faça backup dos seus arquivos e, se desejar, restaure o aparelho para as configurações de fábrica.

2

Instale os emuladores

Baixe e instale o DuckStation, RetroArch e PPSSPP.

3

Copie as ROMs

Organize seus jogos em pastas para facilitar o reconhecimento pelos emuladores.

4

Configure o controle

Conecte via Bluetooth ou OTG e faça o mapeamento dos botões.

5

Ajuste os gráficos

Configure resolução, filtros e desempenho conforme o aparelho.

6

Divirta-se!

Agora é só aproveitar centenas de jogos clássicos.

⚠ Limitações

  • Jogos muito pesados podem exigir ajustes.
  • Celulares com menos de 2GB de RAM podem apresentar lentidão.
  • Nem todos os aparelhos possuem USB OTG.

💡 Dicas Importantes

🔋 Utilize o modo avião durante os jogos.
🎮 Configure corretamente os controles.
📁 Organize as ROMs em pastas.
💾 Faça backup das BIOS.
🚀 Feche aplicativos em segundo plano.
🌡 Evite jogar enquanto o celular carrega.
